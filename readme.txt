Lightweight cash-on-delivery store theme for WooCommerce, made for Arabic stores.

== Description ==

COD Store lets customers order straight from the product page with a short cash-on-delivery form or on WhatsApp, without a cart or checkout. Built right-to-left for Arabic stores.

* Order form on the product page, with ready-made designs.
* WhatsApp ordering (form, WhatsApp or both, store-wide or per product).
* Quantity offers, price box with countdown, thank-you page offer, offer popup.
* Product reviews, related products, order button that stays on screen on phones.
* Currency switcher (display only), ad pixels (Facebook, TikTok, Google).
* Header builder, store notice bar, home hero, search and filters, blog.
* Updates from GitHub releases under Dashboard > Updates.

Requires WooCommerce. The home page product grid is an Elementor widget ("Products Grid (Store)").

== Installation ==

1. Appearance > Themes > Add New > Upload Theme, choose hx-store.zip, then Activate.
2. Install and activate WooCommerce, then add your products.
3. Install Elementor and add the "Products Grid (Store)" widget to your home page.
4. Appearance > Customize to set the theme up.

== External services ==

This theme connects to these services only when you use the matching feature:

* ExchangeRate-API (open.er-api.com): when the currency switcher uses automatic rates, the site asks for the latest MAD exchange rates (no visitor data is sent). Terms: https://www.exchangerate-api.com/terms
* Meta Pixel (connect.facebook.net), TikTok Pixel (analytics.tiktok.com) and Google tag (googletagmanager.com): loaded in visitors' browsers only after you paste a pixel or tag ID in Customize > Ad pixels. Meta: https://www.facebook.com/privacy/policy/ · TikTok: https://www.tiktok.com/legal/privacy-policy · Google: https://policies.google.com/privacy
* WhatsApp (wa.me / api.whatsapp.com): links that open WhatsApp with the order message, only when WhatsApp ordering is on. https://www.whatsapp.com/legal/privacy-policy
* GitHub (api.github.com): checks for new theme releases at most every 12 hours. No site data is sent. https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement
